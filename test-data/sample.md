# QueryReader Markdown 测试文档

## 功能测试

这是一个 Markdown 渲染 **功能测试** 文档，用于验证：

- 标题层级（H1/H2/H3）
- **加粗** 与 *斜体* 文字
- 列表（无序列表）
- 引言块（blockquote）
- 代码段

### 代码示例

```cpp
int main() {
    std::cout << "Hello QueryReader" << std::endl;
    return 0;
}
```

> 引用：好的阅读器应当轻量、快速、支持多种文档格式。
